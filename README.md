# LModel Studio v1.25

Локальное обучение текстовых моделей и чат с ними. Без интернета и внешних API (опционально — локальный HTTP API в Dev Mode).

## v1.25

1. **Параметры** — только редактирование числового значения (NumbersOnly). Создать/удалить нельзя.
2. **Рассуждения** — в чате кнопка «Показать рассуждение» + счётчик токенов.
3. **Статус «Обучена»** — сразу после обучения (фикс: save больше не затирает `isTrained`, редактор и чат перечитывают модель).
4. **Экспорт** — реальные файлы `.onnx` (protobuf MatMul retrieval) и `.tflite` (FullyConnected FlatBuffer).
5. **Dev Mode** — экспорт, локальный API `:8765` (OpenAI-подобный `/v1/chat/completions`), проба рассуждений и токенов.
6. **Только текст** — обучение и чат без вложений/медиа.

## Как открыть

Android Studio → Open → `LModelStudio` → Sync → Run (API 24+).

## API (Dev Mode)

```
GET  http://127.0.0.1:8765/v1/health
GET  http://127.0.0.1:8765/v1/models
POST http://127.0.0.1:8765/v1/chat/completions
GET  http://127.0.0.1:8765/openapi.json
```
